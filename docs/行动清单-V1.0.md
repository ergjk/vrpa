## 0. 三条红线与本清单的落实方式

| 红线 | 含义 | 本清单中的强制约束 |
|---|---|---|
| R1 严禁超前开发 | 只做 V1.0；V1.1（表情/撤回）、V1.2（行为克隆）、生图/多模态**不得有任何具体实现** | M0-05 只允许 `core/interfaces.py` 里的空 Protocol；`redline-check` 扫描 `plugins/`、`brain/`、`act/` 不得出现 `recall`/`emoji`/`tts`/`clone`/`image_gen` 的实现体；M6-06 验收复核 |

## 1. 统一工程约定（所有任务共用，先读这一节）

### 1.1 命令行契约（下文 DoD 全部基于它）

```
python -m wechat_agent <子命令> [参数]
```

| 子命令 | 用途 | 首次交付任务 |
|---|---|---|
| `selftest` | 配置/日志/DB/依赖自检 | M0-02 |
| `doctor [--json]` | 环境体检（依赖/DPI/多屏/窗口/写权限） | M0-07 |
| `validate-tree [--strict]` | 校验假 UIA 树 profile 与锚点图 | M1-05 |
| `calibrate [--element ID] [--add-anchor ID]` | 校准向导 | M1-04 |
| `locate <element_id> [--json]` | 定位单个元素并打印坐标/分数 | M1-03 |
| `probe [--times N] [--report FILE]` | 打印原始剪贴板文本，不入库不回复 | M2-05 |
| `replay --scenario <dedup\|parser\|flow> [--all] [--golden]` | 离线回放（无微信） | M2-04 / M3-07 |
| `db-check [--schema] [--repair]` | 双库结构与迁移检查 | M0-06 |
| `llm-ping [--ask "文本"]` | LLM 连通性/单轮问答 | M5-05 |
| `run [--dry-run] [--fake] [--simulate FILE] [--trace FILE] [--console-script FILE] [--max-hours N] [--report FILE]` | 主进程 | M4-06 |
| `send --chat <名> --text <文本> [--dry-run]` | 控制台接管发送（等价 `/say`） | M6-01 |
| `plugin list\|run <名> [args]` | 插件管理 | M6-04 |
| `report --check FILE` | 浸泡/验收报告判定 | M6-06 |

### 1.2 退出码约定（DoD 用它判定，不要用"看日志"）

| 码 | 含义 |
|---|---|
| 0 | 成功 |
| 2 | 配置/参数错误（`ConfigError`） |
| 3 | 元素定位失败（`ElementNotVisible`） |
| 4 | 发送校验失败（`VerifyFailed`） |
| 5 | LLM 调用失败（`LLMError`） |
| 6 | 数据库/迁移失败（`DBError`） |
| 7 | 分辨率/DPI/窗口与 profile 不符（`ProfileMismatch`） |
| 8 | 红线违规（`RedlineViolation`） |

### 1.3 目录与命名
- 文件路径严格按技术方案 §3.1；新增只允许：`wechat_agent/__main__.py`（`python -m` 入口 2 行 shim）、`tests/fixtures/**`、`docs/**`。
- Python 3.10+，类型标注必写；模块间只通过 `core/interfaces.py` 的协议交互（便于 Fake 注入）。
- 所有随机性走 `core/locks.py` 注入的 `random.Random(seed)`；所有等待走 `Event.wait()`（可打断）。

### 1.4 测试命令统一形式
```powershell
python -m pytest tests/<文件>.py -q
# 期望：N passed, 0 failed；出现 error 也算未通过
```

## 4. M1 · 假 UIA 树（视觉映射层）+ 校准（3.0 人日，Gate G1）

**阶段目标**：界面元素定位能力可用、可校验、可校准；**失败必中止**（不猜坐标）。消息流不参与本阶段。
**阶段交付物**：`perception/uia_tree.py`、`perception/anchor_match.py`、校准向导 `tools/calibrate.py`、`data/uia_tree/*.json` + `data/anchors/*`、`validate-tree`/`locate`/`calibrate` 子命令。

### M1-01 · profile schema 与加载校验

- **涉及文件**：`wechat_agent/perception/uia_tree.py`（新建）、`tests/test_uia_tree.py`（新建）、`tests/fixtures/uia_tree/*.json`（新建，含正常/缺图/成环/display 不符样例）。
- **输入**：`data/uia_tree/<profile>.json`、`data/anchors/<profile>/*.png`。**输出**：`load_profile(path, anchors_dir) -> UiaTree`；`UiaTree.get(id) -> ElementNode`；`UiaTree.validate() -> list[Problem]`。
- **DoD**：

- **人工**：对照技术方案 §4.3 检查示例 profile 字段是否齐全（`message_area/search_box/input_box/send_button/popup_close`）。

### M1-02 · 锚点图多尺度匹配引擎
- **任务描述**：实现 `match_template(crop, anchor_images, match_cfg) -> (score, offset, scale)`：灰度、多尺度（0.9~1.1）、`TM_CCOEFF_NORMED`、大区域降采样、多候选 `top_k`、多张锚点图按序尝试取最优；纯函数、不碰窗口。
- **涉及文件**：`wechat_agent/perception/anchor_match.py`（新建）、`tests/test_anchor_match.py`（新建）、`tests/fixtures/anchors/*.png`（合成图）。
- **输入**：numpy 图像（BGR/RGB）+ 锚点图路径 + 匹配参数。**输出**：`MatchResult(score, offset_x, offset_y, scale, anchor_used)`；`score < threshold` 由调用方抛 `ElementNotVisible`。
- **DoD**：
  ```powershell
  python -m pytest tests/test_anchor_match.py -q
  # 期望 passed：同图（缩放 0.9/1.0/1.1、加噪声 3%）score ≥ 0.95；无关图 score < 0.88；坐标误差 ≤ 2px
  ```

### M1-03 · `locate()` 定位 + 缓存 + 失败语义
- **任务描述**：实现 `locate(element_id) -> Rect`：沿 parent 链找最近已定位祖先（无则取 `client_rect`）→ 裁剪屏幕 → 匹配 → 绝对坐标换算；结果缓存（key=元素+client_rect 哈希，TTL 2s）；`invalidate_all()`；`ElementNotVisible` 抛出且**不提供任何坐标兜底**；`locate` 子命令输出 `--json`。
- **涉及文件**：`wechat_agent/perception/uia_tree.py`（扩展）、`wechat_agent/perception/window.py`（仅 `client_rect` 空壳，M2 补全）、`wechat_agent/main.py`（挂 `locate`）。
- **输入**：profile + 屏幕截图（可用 `vision.screenshot()`）。**输出**：`locate(element_id, *, force_refresh=False) -> Rect(x, y, w, h)`；`cache.invalidate_all()`；CLI JSON：`{"element","rect","score","anchor_used","source"}`。
- **DoD**：
  ```powershell
  python -m pytest tests/test_locate.py -q
  # 期望 passed：缓存命中不打第二次匹配；invalidate 后重匹配；缺锚点图元素抛 TreeConfigError；
  # 无可匹配屏幕内容时抛 ElementNotVisible（退出码 3）
  python -m wechat_agent locate input_box --json; echo $LASTEXITCODE   # 无微信/未校准时期望 3 或 7，不得 0 且返回假坐标
  ```
